# tokcat Windows 预览版

[English](README.md)

在 Windows 10 或 11 上双击 `Tokcat.cmd` 启动。程序需要系统自带的 Windows PowerShell 5.1，不需要 API 密钥。状态点与两行指标默认直接嵌入主屏幕的水平任务栏内部，靠近右侧通知区域的空余位置。启动后详情窗口收起；单击任务栏监控打开详情，右键可隐藏或退出，详情窗口的「任务栏」按钮也可切换显示。重复启动会打开已有的详情窗口。

任务栏背景透明，参考 mac 版使用紧凑的固定宽度单元，指标组之间间隔 4 像素（按缩放比例调整）。网速划分为固定的箭头、约四字符的数值区和单位列，数值右对齐，位数与单位变化不会改变单元宽度；文字按实际绘制上下文测量，避免额外边距。字体采用 9pt Segoe UI 加粗。左侧状态点每列最多三个，整组与文字的上下边缘对齐，超过三个排列到第二列，超过六个时显示额外数量；任务栏不显示运行／等待计数文字。中间上行是输出 tok/s、下行是 Codex 额度，右侧上行是上传网速、下行是下载网速。CPU、GPU、内存默认关闭，可在右键菜单「任务栏指标」中开启，设置保存在 `%LOCALAPPDATA%\Tokcat\taskbar-metrics.json`。GPU 关闭时停止相应采样。

网速、CPU 与内存每秒采样一次；Agent 日志由独立后台读取器每 5 秒检查一次，同一时间仅允许一次扫描。即使日志读取较慢，也不会阻塞每秒指标刷新或任务栏交互。GPU 使用可选的低频后台计数器采样。

程序在后台读取任务栏按钮的占用范围，为自身子窗口寻找空位；不会改变 Explorer 的按钮布局。任务栏没有足够空间、布局不可读或为竖直任务栏时，监控区域会隐藏，详情窗口提示原因；不会回退到桌面悬浮条。任务栏重建后会尝试自动重新嵌入。窗口会随任务栏一起隐藏，支持负坐标和缩放布局；当前只嵌入主任务栏。显示设置保存在 `%LOCALAPPDATA%\Tokcat\taskbar.json`，与旧悬浮条的隐藏设置独立。

在有桌面会话的电脑上，可运行 `powershell.exe -NoProfile -STA -File .\windows\Test-Taskbar.ps1 -RealTaskbar` 验证真实 Explorer 父窗口、任务栏边界和按钮避让。常规打包测试使用隔离父窗口验证嵌入、隐藏、点击和父窗口重建。

任务栏窗口图标和通知区域图标也会显示状态点。关闭主窗口后程序继续运行；若通知区域图标被折叠，可在 Windows 任务栏设置中将它设为始终显示。

窗口列出最近七天的任务、状态、项目、阶段、模型和可用的输出 token 数。双击 Codex、Claude Code、WorkBuddy 或 DeepSeek 任务可阅读本地用户／助手文本；若找不到对应记录则提示不可用。双击 Codex Work 任务打开原会话，双击活动记录打开原始文件；右键也可打开原始记录。阅读器不会显示系统消息、推理、工具输出或图片数据，对话文本只在内存中读取。通知区域最多显示六个状态点：黄色表示运行，橙色表示等待回答、等待授权或长时间无活动，红色表示失败，绿色表示本轮结束。日志安静超过两分钟只表示无新活动，不代表失败。图标悬停提示显示汇总信息；右键任务可将完成或失败提醒标记为已读。提醒保存在 `%LOCALAPPDATA%\Tokcat\reminders.json`，重启后仍匹配的未读提醒会恢复，超过七天的记录会过期。

状态通知默认关闭；如需在任务等待、完成或失败时收到 Windows 通知，可在通知区域图标的右键菜单启用。通知可能显示任务标题，Windows 的通知设置和专注模式会影响其显示。

程序还显示 CPU、GPU、物理内存、网络收发速率、观察到的输出 tok/s 和 Codex 客户端写入本地日志的额度。GPU 数值使用 Windows 性能计数器，显示所有显卡中最繁忙的引擎；计数器不可用时显示「—」，后台读取可能需要数秒。网络速度按活动的非回环网卡求和，虚拟网卡可能导致重复计数。输出速度以约 60 秒内报告的输出 token 变化估算，不含输入和缓存；至少需要两次采样，且可能受到批量上报影响。额度显示记录时间；超过记录的重置时间后显示为不可用，直到客户端写入新记录。额度读取范围是 `sessions` 和 `archived_sessions` 中各最多 20 个最近文件的末尾 512 KiB，短于或等于 48 小时的窗口标为 `5h`，较长窗口标为 `周`。

点击窗口中的「用量统计」可按今天、近 7 天或近 30 天查看本地 Codex 和 Claude Code 日志中的输入、缓存读取、缓存写入和输出 token，按日期、来源、模型与提供方分组。Codex 按会话累计数差分并去重；不完整日志的首个累计数只在能确认属于首次请求时计入，计数器重置后重新建立基线。Claude Code 按消息 ID 合并流式记录，并以该消息最新记录的日期归类；没有消息 ID 时只能按记录标识去重。超大记录会跳过，未上报的 token 分类无法识别，因此统计可能低于完整历史。后台读取不保存对话正文，也不访问网络。

同一视图也读取 OpenClaw 的 `model.completed` 和 Kimi 的 `usage.record` 用量事件；OpenClaw 优先采用最后一次调用的用量。事件必须有有效时间，未记录的 token 分类按零统计。不同文件中复制的事件没有可靠标识时可能被重复计入；相同路径不会重复读取。上述两种 Agent 的活动日志仍不能可靠判断任务状态。

WorkBuddy 和 WorkBuddy AI 的用量从各自 `traces` 目录中的生成记录读取，输入 token 中的缓存部分单独列出；同一文件中相同生成记录的标识只计一次。记录必须包含有效时间，超过 4 MiB 的文件会跳过，窗口显示跳过数量。不同文件中复制的记录可能重复计数，未标注的中转方也可能导致参考单价不适用。

DeepSeek Harness 用量来自会话投影的累计计数差额，仅在输入、输出和两类缓存计数齐全时记录。首次发现会话时只建立基线，之后在 tokcat 运行时观察到的增量记录到 `%LOCALAPPDATA%\Tokcat\dsh-usage.jsonl`，不包含会话 ID 或对话正文。程序关闭期间的用量不会回填；重启后重新建立基线，计数重置也不会被当作新用量。采样间模型或提供方变化时，增量显示为未知模型并保持未计价。这个本地文件可在不需要记录时由用户自行删除。

用量窗口可切换到「CC Switch 代理」视图，读取 `%USERPROFILE%\.cc-switch\cc-switch.db` 中的代理请求并按应用、模型和提供方分组。它只统计 `proxy` 数据来源，最多读取所选周期内最近 100,000 条；其它来源的导入记录不会计入。代理记录可能与 Agent 日志对应同一请求，因此两个视图独立显示，不应相加。费用列显示代理记录中大于零的费用，零值或无效费用标为未计价；这些数据并非实际账单，也不包含其他渠道的用量。

金额是使用参考单价计算的美元估价，**不是实际账单或订阅费用**。默认单价来自本项目的 `UsagePricing.json` 参考目录，可能过时；在用量窗口点击「编辑参考单价」会创建或打开 `%LOCALAPPDATA%\Tokcat\usage-pricing.json`，保存后重新读取即可。此个人副本可在升级时保留。`input`、`cache_read`、`cache_write`、`output` 分别是每百万 token 的美元单价，可选 `provider` 指定提供方。没有匹配单价或缓存写入单价的 token 会单独显示为未计价；已知的其他提供方不会自动套用官方单价，未标注提供方则按官方单价估算。Claude Code 本地记录通常不标注中转商，可能因此使用不适用的单价。Agent 日志视图不包含 CC Switch。

当前支持：

- Codex CLI／桌面端本地会话和 Codex Work 本地目录。
- WorkBuddy、WorkBuddy AI 和 DeepSeek Harness 的本地会话状态。
- Claude Code 的可选 hooks，见下方安装方式。
- OpenClaw、Kimi 的本地活动记录；这些记录不提供可靠的运行、等待或完成状态，因此显示为未知。

任务状态读取首先检查 Codex 日志末尾 512 KiB；若没有生命周期事件，会流式读取完整日志并跳过超过 2 MiB 的单条记录。来源未提供的信息不会推断。Windows 版目前尚未实现其他 Agent 接入和桌宠，详细数据路径见 [英文说明](README.md)。

如需启用 Claude Code 状态，在项目根目录运行以下命令并重启现有 Claude 会话：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\Configure-ClaudeHooks.ps1
```

需要 Claude Code 2.1.295 或更高版本。配置脚本保留已有设置和其他 hooks，并在设置文件旁创建带时间戳的备份。hooks 只写入会话 ID、项目路径、状态、阶段和时间，不保存提示词、回复或工具输入。同步 hooks 每次事件可能增加少量启动延迟。移动 tokcat 文件夹前，应先使用下方命令移除旧路径的 hooks，移动后重新启用：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\Configure-ClaudeHooks.ps1 -Remove
```

移除操作保留其他 hooks 和已有状态文件。可使用以下命令验证本地解析和窗口初始化：

```powershell
powershell.exe -NoProfile -File .\windows\Test-Monitor.ps1
```

在项目根目录运行 `powershell.exe -NoProfile -File .\windows\Package.ps1` 可在 `dist/` 下生成独立 ZIP。解压后运行 `tokcat-windows\Tokcat.cmd`；Windows CI 也会将 ZIP 保存为工作流产物。
