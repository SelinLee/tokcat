# 用量统计口径

统计页支持日、周、月和任意历史日期。日视图的额度图显示截至所选日期的近 14 天；周、月视图显示所选周期内的每日数据。周起始日遵循系统日历。日期是查询缓存键的一部分，异步查询不会覆盖后来选择的日期。

## Tokens 与速度

总 Tokens 包含四个不重叠的字段：非缓存输入、缓存读取、缓存写入、输出。分类沿用各适配器规范化后的 `TokenEvent`；未上报的分类无法单独识别。输出包含来源日志计入输出的推理 tokens，不额外重复相加。

`tok/s ≈` 是有有效耗时的样本输出总量除以其耗时总和，不是各请求速度的算术平均。只接受 0.1 秒至 10 分钟之间（不含 10 分钟）的有限正耗时，且输出必须大于零。当前 `latencyMs` 可能来自日志时间差，包含等待、工具执行等时间，所以此指标为历史输出速度估算，不是流式解码速度，也不是菜单栏的全部 token 实时吞吐。无耗时样本显示空缺。

## Codex 每 1% 订阅额度对应的 Tokens

从本机 Codex 的 `sessions` 和 `archived_sessions` 读取实际 `token_count` 事件，不读取凭据、不发出网络请求。只使用原生 OpenAI provider（或未标注 provider、但存在额度记录）的日志。其他服务商的请求不混入此指标。

- 使用每个会话的累计 token 差分；重复上报的 `last_token_usage` 不会重复计入。
- 第一个累计数作为基线；只有当它等于单次请求量、能够识别为新会话首次请求时才计入全局区间。
- 全局按时间排序，去除相同会话和时间戳的重复记录。短时窗口和周窗口分别计算。
- 同一天、同一重置时间、同一窗口长度及套餐内，收集到正向额度变化后计算匹配区间。跨日、额度重置、回退、缺失额度时重新建立基线。
- 每日比值为匹配区间的 token 总和 / 消耗百分点总和。尚未出现额度增长的尾段不计入，没有可配对区间的日期不补零。
- 每日柱状图按模型分色堆叠：各模型匹配区间的 token 数量共用当天消耗百分点作分母，因此各段相加等于每日总值，不把共享额度伪分配为各模型独立额度。模型来自对应的 `turn_context`，未上报时显示「未知模型」；图例、悬停和每日明细保留模型信息。
- 顶部卡片按所选周期加权汇总；主图可以切换总量及四种 token 分类，悬停与展开明细可查看数值和观测消耗。

这个比值是本地观测值，不是官方固定兑换率。额度取整、额度更新延迟、混合模型、其他设备使用、账户切换和不完整日志都会影响结果。日志没有稳定的账户标识，无法完全分离同套餐的多账户记录。Codex 通常提供短时与周额度，日图表示按自然日聚合，不假设存在每日重置的订阅额度。

首次按需扫描历史日志；同一进程内未改动文件复用紧凑的计数缓存。读取在后台进行，跳过超大行及未写完的末行，不保留对话正文。

## 验证

```sh
swift test --filter 'UsageMeasurementsTests|UsageStatsTests|CodexUsageMonitorTests|UsageStoreTests'
swift run TokcatApp --preview-usage-dashboard /tmp/tokcat-usage-preview
```

预览使用独立临时数据库、设置域和合成日志，不启动监控器。它同时验证历史日期查询、缓存命中与旧查询竞态，并生成浅色、深色和 900 点窄窗口截图。
